# DALA App - Dream, Act, Learn, Achieve

A JavaFX-based affirmation application designed to provide users with positive daily affirmations to support mental wellness and emotional well-being.

## Description

DALA is an interactive desktop application that helps users start their day with positivity. The app offers multiple affirmation categories and allows users to personalize their experience by creating their own affirmations. Built with JavaFX, DALA provides an intuitive and visually appealing interface to promote self-care and positive thinking.

### Main Features
**Welcome Interface**: A warm welcome page that invites users to "Start Your Journey" toward positivity

**Category Selection Menu**: Choose from multiple affirmation categories: 

- Motivational, Self-Love, Funny, and Random.
  
**Random generator**: Shows a new affirmation with one tap (per category or across all).

- Write your own: Users can add custom affirmations.
  
**CSV file I/O**: Loads built-in + user-added affirmations at startup and saves new ones for next time.

**Accessible UI (JavaFX)**: Clean screens—Welcome → Menu → Category → Write-Your-Own—with.
